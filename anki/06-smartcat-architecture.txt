#deck:DotNet Interview Guide::06 Architectural patterns at Smartcat
#tags column:3
What two architecture styles does Smartcat run at the same time?	A large <b>modular monolith</b> (<code>smartcat/</code>, .NET 10) and a set of <b>services extracted from it</b> (PTS, WOS, Scol, FDA, ...).<br>Services were cut out along boundaries that already existed in the monolith.	ch06 architecture monolith smartcat
What is a modular monolith?	One deployable binary with strong, enforced internal boundaries: each module has a published contract, private internals and private data, and dependencies point one way.	ch06 architecture monolith
What is a &quot;distributed monolith&quot;?	Microservices without real boundaries: services call each other synchronously and change together.<br>You pay the network cost but get no independent deploy or failure isolation.	ch06 architecture microservices
What do microservices really buy you, compared with a modular monolith?	<b>Independent change and ownership</b>: own release, own data, own scaling, failure isolation.<br>Not &quot;scalability&quot; by itself: a monolith split by role also scales horizontally.	ch06 architecture microservices
Give four good reasons to extract a context into its own service.	<ul><li>Different scaling profile (PTS: busiest Kafka event hub)</li><li>Team needs its own release cadence</li><li>Different technology/runtime need (FDA: heavy file parsing)</li><li>A clear, stable boundary already exists</li></ul>	ch06 architecture microservices
What is the strangler fig pattern?	Replace a legacy part step by step: new code grows next to old, traffic moves in small steps, the old part is removed when unused.<br>Each step stays reversible.	ch06 strangler architecture
Why does <code>smartcat/Features/ProjectTasks</code> still exist although PTS owns project tasks?	It is an <b>adapter / anti-corruption layer</b>: monolith callers keep <code>IProjectTaskService</code>, but the module binds the PTS <code>ApiClient</code> (<code>bindPtsApi</code>). A strangler step: callers unchanged, ownership moved.	ch06 strangler pts smartcat
In what order does PTS isolate its read path from the monolith?	Own the query &rarr; split foreign columns &rarr; drop the monolith from the read path.<br>Each step is pinned by a characterization test.	ch06 strangler pts smartcat
What is the most common mistake when extracting a service?	Keeping a synchronous call back into the monolith &quot;for now&quot;. It creates a cycle (monolith &rarr; service &rarr; monolith), so neither side can deploy or fail alone.	ch06 strangler cycles
What is a bounded context?	The area inside which one model and one vocabulary are consistent (DDD).<br>Example: &quot;task&quot; = translation work in PTS, but = background job in <code>Smartcat.TaskProcessing</code>.	ch06 ddd bounded-context
At Smartcat, what is a bounded context in the monolith, and who owns it?	Each <code>Features/*</code> folder (about 40). Owned by a team, <b>roughly 1:1 with <code>CODEOWNERS</code></b>.	ch06 bounded-context smartcat
List the projects of a typical monolith feature and their roles.	<ul><li><code>.Contract</code>: published surface</li><li><code>.Module</code>: domain, repositories</li><li><code>.WebModule</code>: controllers</li><li><code>.TaskModule</code>: background tasks</li><li><code>.ConsumerModule</code>: Kafka handlers</li><li><code>.Tests</code></li></ul>	ch06 module-layout smartcat
Which project of another feature may your feature reference?	Only its <code>*.Contract</code> (or the service's <code>*.ApiClient</code>). Never its <code>*.Module</code> internals.	ch06 module-layout boundary-rules smartcat
Why does <code>Billing.ConsumerModule</code> have folders named Projects, WorkOrders, ProjectTasks?	Billing learns about other contexts by <b>consuming their events</b>, grouped by source context (rule 3: events, not shared state).	ch06 module-layout events smartcat
Why split a feature into WebModule, TaskModule and ConsumerModule projects?	So the host loads only what a role needs (Web vs Processing pods), and dependencies stay honest (a TaskModule cannot use <code>HttpContext</code>).	ch06 module-layout roles smartcat
What two things must you do so a new monolith controller is served?	Register it with <code>AddController&lt;T&gt;()</code> in its <code>*.WebModule/WebModule.cs</code>, and tag it with <code>[Route]</code> + <code>[TSModule]</code>. The WebModule itself must be in <code>Modules.cs</code>.	ch06 module-layout smartcat
What does <code>[TSModule(&quot;payment-constants&quot;)]</code> on a controller do?	It drives TSClientGen, which generates the frontend TypeScript API client from the controller. A backend contract change shows up as a TS type error.	ch06 frontend smartcat
What is a composition root, and where is it in the monolith?	The one place where the app is wired together. In the monolith: <code>WebApplication/WebService/Modules.cs</code> (about 190 <code>.Module&lt;T&gt;()</code> calls, grouped by role).	ch06 composition-root smartcat
What happens if you create a new <code>*.Module.cs</code> but forget to register it in <code>Modules.cs</code>?	It compiles, runs, and is <b>silently never loaded</b>. No error.	ch06 composition-root traps smartcat
What are the monolith's run profiles?	<code>Processing</code>, <code>SignalR</code>, <code>Web</code>, <code>Admin</code>, <code>ClientPortal</code>, <code>FullWeb</code> (default = Web + SignalR + Processing). Set with <code>--profile</code>, not <code>--roles</code>.	ch06 roles smartcat
Why can a bug hide locally but appear in staging when a module is in the wrong role group?	Locally the default <code>FullWeb</code> profile loads all roles. In Kubernetes each profile is its own pod set, so a module in the wrong group does not run where it should.	ch06 roles traps smartcat
Why does a monolith benefit from run profiles?	Workloads scale and fail differently: slow Kafka consumers must not starve HTTP threads; a Web hot fix should not restart long tasks. One binary, several pod sets.	ch06 roles scaling smartcat
How is real-time UI push done in the monolith?	Emit an event. The <code>--profile SignalR</code> pod consumes a Kafka topic and broadcasts. You do not call SignalR from a Web request.	ch06 signalr kafka smartcat
Sketch the PTS <code>src/</code> layout.	<code>Service/</code> host, <code>WebModule/</code> controllers, <code>ProjectTasks.Module/</code> domain, <code>ConsumerModule/</code> (Dispatchers + Handlers), <code>Contracts.Events/</code>, <code>Contracts/</code> + <code>ApiClient/</code>, <code>Common/</code>, <code>Migrations/</code>, <code>Tests/</code>.	ch06 microservice-layout pts smartcat
What does the newer microservice template put under <code>src/API/</code>?	<code>Api.Contracts</code> (DTOs, enums, typed IDs), <code>Api.Contracts.Events</code> (Kafka events), <code>Api.Client</code> (NSwag client), <code>GatewayModule</code> (thin gateway proxies).	ch06 microservice-layout apiclient smartcat
What roles does a Smartcat service binary have?	<code>Web</code> (HTTP, Swagger) and <code>Processing</code> (Kafka consumers, tasks, outbox relay). Default is both; Kubernetes splits them.	ch06 roles microservice-layout smartcat
What is Smartcat.AppPlatform / ModuleHosting?	The internal framework all services and the monolith run on: modules, roles, layered config, typed HTTP clients, outbox/Kafka, TaskProcessing, Mongo helpers, migrations.	ch06 appplatform smartcat
Why does Smartcat have an internal platform instead of each team writing its own outbox and retries?	Outbox, DLQ, task capture and migrations are hard to get right; a platform turns hard problems into conventions. Cost: learning curve and platform upgrades across repos.	ch06 appplatform tradeoffs smartcat
State the seven boundary rules of the monolith.	<ol><li>One module per change</li><li>A module owns its model</li><li>Contracts or events, never shared state</li><li>No dependency cycles</li><li>Invariants inside the aggregate</li><li>Independently testable</li><li>Thin seams, no speculative coupling</li></ol>	ch06 boundary-rules smartcat
Rule 2: from another assembly, do you depend on a context's <code>*Service</code> or its <code>*Repository</code>? Why?	The <b>Service</b>. A repository is that module's internals: it exposes storage shape and skips the owner's rules (soft delete, permissions, caching).	ch06 boundary-rules smartcat
What is wrong with this constructor in a Marketplace WebModule service?<pre><code>public TeamPageService(IAccountUserRepository repo)</code></pre>	It reads another context's repository (boundary rule 2). Depend on <code>IAccountUserService</code> from the owner's contract instead. (Real case: monolith MR 27065.)	ch06 boundary-rules review smartcat
Rule 3: you need another context's data on your read path. What do you do?	Consume its event and <b>materialize your own read model</b>. Do not sync-join into its tables.	ch06 boundary-rules events smartcat
Rule 4: what two things does &quot;no dependency cycles&quot; forbid?	A depending on B <i>and</i> B on A; and any synchronous call back into a context that already lives as its own service.	ch06 boundary-rules cycles smartcat
Why is a sync cycle between the monolith and PTS dangerous at runtime?	Cascading failure: a slow monolith makes PTS slow, which makes the monolith slower. Neither can deploy, scale or fail alone.	ch06 cycles resilience
Rule 5: where do invariants live, and what do commands and queries do?	Inside the aggregate, enforced once. Commands change state and emit domain events (outbox); queries never mutate.	ch06 boundary-rules ddd smartcat
What is an aggregate (DDD)?	A cluster of objects changed together as one unit, with one root that guards its rules. Outside code changes it only through the root.	ch06 ddd
Rule 6: what does it say about a change you cannot unit-test without half the monolith?	The boundary is wrong: fix the boundary. Use constructor injection, I/O behind seams, fakes at the boundary.	ch06 boundary-rules testing smartcat
Rule 7: what does &quot;structure ratifies boundaries; it never anticipates them&quot; mean?	Draw a boundary (abstraction, reference, project) only when you have proof it is real, for example its second use. No cross-module references &quot;for convenience&quot;.	ch06 boundary-rules smartcat
Name the five STOP-litmus triggers.	A change that: imports another module's internal type; adds a sync call forming a cycle; lets a query mutate or a command return another context's rich data; shares a collection/entity across contexts; makes a module untestable in isolation.	ch06 boundary-rules smartcat
What is a downstream, event-fed read model?	A copy of upstream data, shaped for local queries, kept fresh by consuming upstream events. The downstream never asks upstream at request time.	ch06 read-model events
How does PTS get a document's new title after a rename in CAT?	CAT writes the document + <code>DocumentTitleChanged</code> to its outbox; the relay publishes to Kafka; PTS's <code>DocumentTitleChangedHandler</code> calls <code>ScopeService.ChangeDocumentName</code> to update its Scopes.	ch06 read-model pts smartcat
What is the price of an event-fed read model?	Eventual consistency: for a short time the copy is stale. Fine for a document title; maybe not for a balance or a permission.	ch06 read-model consistency tradeoffs
PTS rule: what happens to foreign, display-only fields such as cost?	They stay foreign. They are composed <b>above</b> PTS (frontend or BFF) after the query, never joined in, never a sort/filter key in PTS.	ch06 read-model pts smartcat
Product wants PTS to sort tasks by cost (owned by billing). What is the architectural problem?	PTS may sort and filter only on fields it owns. Sorting by a copied cost makes PTS own a second truth for cost. Push back, compose in the BFF, or make it a field PTS truly owns via a dedicated event.	ch06 read-model ownership pts smartcat
Name five problems an event-fed read model must handle.	Duplicates (idempotency), ordering (partition key), lost publish (outbox), poison messages (DLQ), existing data (backfill). Plus drift (reconciliation).	ch06 read-model events
What does CQRS-lite mean at Smartcat?	No separate databases, but a strict rule: commands change state and emit events; queries never mutate; commands do not return another context's rich data.	ch06 cqrs smartcat
Why is a GET that mutates state dangerous?	Caches, retries, prefetch and server-side rendering call GETs freely, so the side effect happens at surprising times. And replacing that GET silently drops the side effect.	ch06 cqrs
What monolith trap shows why you must trace what an old GET <i>mutated</i>?	Some project GETs (and the Razor server render) clear the &quot;unseen assignments&quot; badge. Swapping to a narrower GET dropped the clear; response field-parity tests did not notice. Fix: explicit <code>POST Projects/{id}/opened</code>.	ch06 cqrs traps smartcat
How do Smartcat services call each other synchronously?	Through the target's NSwag-generated <code>*.ApiClient</code> NuGet package. Never with a raw <code>HttpClient</code>.	ch06 apiclient smartcat
List the four steps to start calling another service.	<ol><li>Add <code>&lt;PackageReference Include=&quot;Smartcat.X.ApiClient&quot; /&gt;</code></li><li>Add <code>.ConfigureXClient()</code> to the <code>HttpClientSettingsBuilder</code> chain</li><li>Add <code>&quot;XApi&quot;: { &quot;url&quot;: &quot;&quot; }</code> to <code>common.json</code> + per-env URLs</li><li>Inject <code>I{Controller}Client</code>, handle <code>XApiException</code></li></ol>	ch06 apiclient smartcat
Your new ApiClient is registered but every call fails with a missing URL. What is the likely cause?	The JSON config section name does not match the <code>configurationSectionName</code> constant inside the package's registration extension.	ch06 apiclient config smartcat
Why does nswag.json use <code>generateDtoTypes: false</code>?	DTOs come from the hand-written, documented <code>Api.Contracts</code> project (imported via <code>additionalNamespaceUsings</code>), so client and server share one contract.	ch06 apiclient smartcat
How must published contracts (<code>*.Contracts</code>, <code>*.ApiClient</code>, <code>*.MQEvents</code>) change?	<b>Additively only</b>: new optional fields and endpoints; never rename or remove in one step. Even an <code>[Obsolete]</code> in a consumed client can break a <code>TreatWarningsAsErrors</code> build.	ch06 apiclient contracts smartcat
Which review-architecture rules flag hand-rolled HTTP clients?	A17: new <code>*Client</code> or raw <code>PostAsJsonAsync</code> where a generated SDK exists. A6: client config registered in the consumer instead of an <code>AddXClient()</code> extension in the client library.	ch06 review apiclient smartcat
Where is service-to-service auth configured?	Inside the ApiClient's registration extension. The consumer only provides config values (for example <code>appId</code>/<code>secretKey</code> in the API config section).	ch06 auth s2s smartcat
Where do real service credentials live?	Never in code or base <code>common.json</code>. Production values come from Kubernetes secrets (files show <code>STORED_IN_PRODUCTION_SECRET</code>).	ch06 auth config security smartcat
A call has a valid service credential. Is the caller allowed to do anything?	No. A service identity is not a user. Pass <code>workspaceId</code>/<code>userId</code> explicitly and check access on the owner side.	ch06 auth security
Which env variables select the config files, and what does each mean?	<code>ENV_GROUP</code> (development/staging/production/testing), <code>ENV_NAME</code> (local, static, europe, ...), <code>ENV_NAMESPACE</code> (instance name, prefixes DB, Kafka, S3).	ch06 config smartcat
What is the role of the base <code>.configurations/common.json</code>?	It is the <b>schema</b>: every key the service uses, with environment-independent defaults. Env files override only what differs.	ch06 config smartcat
A new config key works in Europe but a customer in Asia sees wrong behaviour. Likely cause?	The key was not added for all three production regions (Europe, America, Asia), so a default applied.	ch06 config traps smartcat
Locally PTS never sees monolith events. What config value is the first suspect?	<code>kafka.namespace</code> must be the same in both services (<code>develop.&lt;you&gt;.</code>), or they use different topics.	ch06 config kafka traps smartcat
What three pieces define a backend feature flag?	A <code>FeatureKey</code> enum value (unique id + <code>[FeatureName]</code>), a <code>FeatureDefinition&lt;T&gt;</code> class, and DI registration <code>AddSingleton&lt;FeatureDefinition, MyDefinition&gt;()</code>. Plus a <code>FeatureValuesV2</code> property for the frontend.	ch06 feature-flags smartcat
Name the three <code>FeatureType</code> values.	<code>Provisioned</code> (manual/subscription on-off), <code>Rollout</code> (gradual, permanent), <code>FeatureParameter</code> (enum/config extending a feature).	ch06 feature-flags smartcat
How is a feature flag's scope (workspace, org, user) chosen?	The definition is scope-agnostic; the <b>service method</b> picks the scope. <code>GetFeaturesForChainedEntities</code> resolves org &rarr; workspace &rarr; user, most specific wins.	ch06 feature-flags smartcat
What is the bug?<pre><code>var on = features.IsFeatureOn(Features.MyFeature);</code></pre>(the definition default was changed to true)	<code>IsFeatureOn</code> returns false for an absent value and ignores the definition default. Use <code>features.GetFeature&lt;bool&gt;(featureDefinitions[FeatureKey.X])</code>.	ch06 feature-flags smartcat
Why must a background job not store a snapshot of feature flags from <code>HttpContext</code>?	review-architecture A9: the snapshot goes stale. Store identity (<code>accountId</code>, <code>workspaceId</code>) and re-resolve flags in the background context.	ch06 feature-flags review smartcat
Why can the same frontend bundle call different backends?	API calls are relative to the browser origin. Served by the monolith it calls the monolith; served by PTS it calls PTS (which has explicit routes and no reverse proxy).	ch06 frontend smartcat
What role does each infrastructure component play at Smartcat: MongoDB, Kafka, Elasticsearch, S3?	Mongo: primary DB per service (replica set). Kafka: inter-service events and UI push. Elasticsearch: full-text search (monolith only). S3: files.	ch06 infrastructure smartcat
What does review-architecture A1 flag, and why is it a BLOCKER?	DI lifetime mixing: same interface with two lifetimes, or a singleton consuming a scoped dependency. It compiles and breaks at runtime under load.	ch06 review di
What does review-architecture A16 flag?	<code>IServiceProvider</code> injected into business logic (service locator). Declare dependencies in the constructor; use <code>IServiceScopeFactory</code> only with a reason.	ch06 review di
What does review-architecture A31 flag?	An invariant enforced only at callers (the same <code>if (x.Status == ...)</code> in 2+ places). Move the precondition into the domain method.	ch06 review ddd
What is the fastest signal of a boundary violation in a diff?	A new <code>using</code> of another feature's internal namespace (for example its repositories or DAL).	ch06 review boundary-rules
How do you explain consistency in the Smartcat design?	Strong inside one aggregate/transaction; eventual across contexts via outbox + Kafka; say what the user sees in the gap and why it is acceptable for that data; plan reconciliation for drift.	ch06 system-design consistency
Why do event-fed read models improve latency?	The read path becomes one local query: no network hop and no dependency on upstream health. Work moves from read time to write time.	ch06 system-design latency
What does a modular monolith give a team, and what does it not give?	Autonomy of <b>code</b> (own module, private model). Not autonomy of <b>release</b>: one build, one release train. That is the main reason a context leaves.	ch06 system-design autonomy
What happens if the PTS Kafka consumer is down for an hour?	Consumer lag grows and the read model is stale, but no data is lost (offsets are not committed); on recovery it replays. Monitor lag and know what the UI shows meanwhile.	ch06 system-design kafka
Interviewer: what follow-up separates a senior from a staff answer on &quot;monolith or microservices&quot;?	Ask &quot;how would you get there from here?&quot;. Senior draws good boundaries. Staff plans the path: strangler steps, characterization tests, backfill, reconciliation, contract versioning, and reasons from team structure and cost.	ch06 interviewer system-design
Interviewer: name three red flags in an architecture answer.	&quot;Microservices are always better&quot;; a shared database as integration; synchronous calls in both directions &quot;with retries&quot;; no answer to &quot;what if the consumer is down?&quot;.	ch06 interviewer
Interviewer: a good probe for ownership thinking?	&quot;Your service needs a field another team owns, and product wants to filter by it. What do you do?&quot; Look for ownership reasoning and an alternative, not just &quot;copy it&quot;.	ch06 interviewer read-model
Interviewer: you show a diff that reads another module's repository. What is a staff-level review answer?	Names rule 2 and suggests the Service; also asks why the contract lacks the needed method and proposes adding it, or consuming an event for a local read model.	ch06 interviewer review
