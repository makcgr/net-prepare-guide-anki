What is the Smartcat standard pattern for a mandatory field on a Mongo model?	<pre><code>[BsonElement("accountId"), BsonRequired]<br>public required Guid AccountId { get; init; }</code></pre><code>required</code> + <code>init</code> make the compiler enforce it; <code>[BsonRequired]</code> makes deserialization fail loudly if missing.	ch09 mongodb models smartcat
Why always set <code>[BsonElement(&quot;camelCase&quot;)]</code> explicitly?	The database field name becomes explicit and stable: renaming the C# property does not rename the stored field.	ch09 mongodb models smartcat
What does <code>[BsonIgnoreIfDefault]</code> give you on an optional field?	The field is not written when it has its default value: smaller documents, and old documents without the field read as default. A new optional field needs no migration.	ch09 mongodb models migrations smartcat
Why store enums as strings (<code>[BsonRepresentation(BsonType.String)]</code>)?	Reordering or inserting enum members cannot silently change the meaning of stored ints, and the data is readable in the shell.	ch09 mongodb models smartcat
Why keep separate classes for the DB entity, the API request and the API response?	A storage change must never change the public API, and vice versa. Each model can evolve on its own.	ch09 mongodb models smartcat
What does <code>[BsonKnownTypes(typeof(VolumeScope), typeof(DocumentScope))]</code> do?	Enables polymorphic storage: the driver writes a discriminator <code>_t</code>, so one collection holds several subtypes (PTS <code>Scope</code>).	ch09 mongodb models
How are C# Guids stored in the Smartcat monolith?	As BinData <b>subtype 3</b> (CSharpLegacy, &quot;CSUUID&quot;), registered globally. In the shell: <code>CSUUID('&lt;guid&gt;')</code>.	ch09 mongodb guid smartcat
A Guid filter returns nothing, but the document exists. First suspect?	Guid representation mismatch: a hand-built <code>BsonBinaryData</code> or subtype 4 vs stored subtype 3. Filter via typed <code>Builders&lt;T&gt;.Filter</code>; in tests, register serializers.	ch09 mongodb guid traps smartcat
Is the monolith's <code>DocumentId</code> a Guid?	No. Legacy rows store an <code>int32</code>, modern rows an <code>ObjectId</code>, via a custom serializer. Never treat it as a Guid or string in a filter.	ch09 mongodb guid smartcat
Embed or reference: what are the main criteria for embedding?	Read together with the parent, bounded size, changes together with the parent. Then one document write is atomic and no join is needed.	ch09 mongodb document-design
What is the maximum BSON document size, and what usually reaches it?	16 MB. Usually an unbounded array that grows per user, run or event (review-architecture A29).	ch09 mongodb document-design
What is wrong with this model?<pre><code>[BsonId] public Guid AccountId { get; init; }<br>[BsonElement("entries")] public List&lt;ActivityEntry&gt; Entries { get; init; } = [];<br>// update: Push(a =&gt; a.Entries, entry)</code></pre>	One document per account with an array that grows forever: it approaches 16 MB and gets slower long before. Store one document per entry, indexed by <code>(accountId, createdAt)</code>, or bucket per day.	ch09 mongodb document-design review
What is the $group 16 MB trap (DEV-13826)?	<code>$push</code> of per-document objects into a <code>$group</code> keyed by a low-cardinality field: the one output document grows with input size and fails with <code>BSONObj size ... is invalid</code>. Bound the accumulator by domain cardinality.	ch09 mongodb aggregation smartcat
Does <code>AllowDiskUse</code> fix a <code>BSONObj size is invalid</code> error?	No. It only lets a blocking stage spill its 100 MB working set to disk. It does not raise the 16 MB document limit.	ch09 mongodb aggregation
What is a lost update?	Two processes read the same document, change it in memory and write it back; the later write overwrites the earlier change.	ch09 mongodb concurrency
Fix this race:<pre><code>var s = await col.Find(x =&gt; x.Id == id).SingleAsync();<br>s.Progress += inc;<br>await col.ReplaceOneAsync(x =&gt; x.Id == id, s);</code></pre>	Use an atomic server-side operator: <code>UpdateOneAsync(x =&gt; x.Id == id, Builders&lt;Scope&gt;.Update.Inc(x =&gt; x.Progress, inc))</code>, or <code>FindOneAndUpdate</code> if you need the new state.	ch09 mongodb concurrency
When do you use <code>FindOneAndUpdate</code> instead of <code>UpdateOne</code>?	When you need the document before or after the update. It updates and returns it in one atomic step, so no separate (racy) find.	ch09 mongodb concurrency
<code>$push</code> vs <code>$addToSet</code>?	<code>$push</code> always appends (use <code>$each</code> for many). <code>$addToSet</code> appends only if the value is not already present.	ch09 mongodb updates
Why must outbox events be persisted with <code>PushEach</code>, never <code>Set</code>?	<code>Set</code> overwrites the <code>mqEvents</code> array, so events added by a concurrent writer are lost. <code>PushEach</code> appends atomically.	ch09 mongodb outbox smartcat
What does review-architecture A22 flag, and what are the fixes?	A loop of <code>UpdateOne</code>/<code>DeleteOne</code> for one domain operation (can stop halfway). Fix: put the invariant in one document, <code>UpdateMany</code> with <code>ArrayFilters</code>, or a transaction.	ch09 mongodb atomicity review
What do Mongo transactions require, and how does Smartcat thread them through repositories?	A replica set. Write methods take <code>IClientSessionHandle session = null</code> and call the session overload when present.	ch09 mongodb transactions smartcat
What is optimistic concurrency control (OCC) in Mongo?	Read the document with its version, apply the change, then update with a filter on <code>id AND version</code> and set a new version. No match = someone else won: re-read and retry (bounded).	ch09 mongodb concurrency occ
How does PTS implement OCC?	<code>IConcurrentUpdatable</code> with a <code>ChangeStamp</code> Guid; <code>UpdateWithOcc</code> filters on Id + ChangeStamp, sets a new stamp, throws <code>ConcurrencyException</code> if nothing matched; <code>ConcurrencyHelper.RetryAsync</code> re-reads and re-applies.	ch09 mongodb occ pts smartcat
Why is a timestamp a poor concurrency token?	Clocks differ between pods, and a timestamp is set before the transaction commits, so a write can become visible later with an older stamp. Use a version counter or stamp (PTS <code>ProgressVersion</code>).	ch09 mongodb occ
You add a <code>version</code> field to an existing collection. Why does <code>Filter.Eq(x =&gt; x.Version, 0)</code> miss old documents?	Old documents do not have the field; Eq 0 does not match missing. Backfill it, or filter <code>Or(Eq(Version, current), Exists(Version, false))</code> (review-architecture A10).	ch09 mongodb occ review
Fix this N+1:<pre><code>foreach (var id in ids)<br>    list.Add(await col.Find(r =&gt; r.Id == id).FirstOrDefaultAsync());</code></pre>	One query: <code>col.Find(Builders&lt;T&gt;.Filter.In(r =&gt; r.Id, ids)).ToListAsync()</code>, then zip results back (review-architecture A20).	ch09 mongodb performance review
What does review-architecture A21 flag?	Unbounded scans: <code>Find(Filter.Empty)</code> without limit, <code>GetAll()</code> endpoints, in-memory <code>GroupBy</code> over a collection. Paginate or push work into an aggregation.	ch09 mongodb performance review
Why does a paginated list need a unique tiebreaker in its sort?	Without a total order, documents with equal sort values can appear on two pages or on none. Add <code>_id</code> as the last sort key.	ch09 mongodb pagination
Keyset pagination vs <code>Skip</code>?	Keyset (&quot;after (deadline, id) = (X, Y)&quot;) uses the index to jump; <code>Skip(N)</code> still walks N index entries, so deep pages get slow.	ch09 mongodb pagination
What does the monolith's <code>CollectionWithDeletableFlag&lt;T&gt;</code> do, and what is its escape hatch trap?	Every read auto-adds <code>IsDeleted == false</code> (do not add it again). <code>AsMongoCollection()</code> returns the raw collection without that filter: re-apply it yourself.	ch09 mongodb soft-delete smartcat
When may you read from a secondary, and when never?	Read-only paths that tolerate lag may use <code>database.AsSecondary()</code>. Never read your own just-written data from a secondary (replication lag).	ch09 mongodb replication smartcat
What is the ESR rule?	Order compound index fields: <b>E</b>quality first, then <b>S</b>ort, then <b>R</b>ange. Equality narrows to one sorted run, so no in-memory sort; range then cuts it.	ch09 mongodb indexes esr
Design the index: filter <code>{ accountId, status, deadline &lt; T }</code>, sort <code>createdAt desc</code>.	<code>{ accountId: 1, status: 1, createdAt: -1, deadline: 1 }</code> (ESR). Name it <code>IDX_AccountId_Status_CreatedAt_Deadline</code>. Verify with <code>explain()</code>.	ch09 mongodb indexes esr
Which queries can the index <code>{ a: 1, b: 1, c: 1 }</code> serve?	Queries on its prefixes: <code>a</code>, <code>a,b</code>, <code>a,b,c</code>. Not <code>b</code> alone or <code>c</code> alone.	ch09 mongodb indexes
What is a covered query?	A query whose filter and returned fields are all in the index, so Mongo never loads the documents. PTS has explicitly &quot;covered&quot; statistics indexes.	ch09 mongodb indexes
What is a partial index, and a key condition for it to be used?	An index over only documents matching a filter (small, cheap). The query filter must imply the partial filter, or Mongo cannot use it.	ch09 mongodb indexes
Why does the outbox index use <code>PartialFilterExpression: mqEvents.rev exists</code>?	At rest the outbox queue is empty, so the index holds almost nothing, yet the relay finds pending events fast.	ch09 mongodb indexes outbox smartcat
Why does PTS's partial index on <code>progressDirty: true</code> also include <code>_id</code>?	All keys of a partial index on one true-valued flag are identical, so there is no order to page by. <code>_id</code> gives the sweep a stable order.	ch09 mongodb indexes pts smartcat
What does review-architecture A27 say about unique indexes?	Scope uniqueness by tenant: <code>(accountId, name)</code>, not <code>name</code> alone. Example: <code>IX_AccountId_Name</code> on client net rates.	ch09 mongodb indexes review smartcat
How do you allow one live row per key with soft delete?	Unique index with a partial filter <code>isDeleted == false</code>, so deleted rows do not block a new one (PTS <code>IX_TaskId_DocumentId_NonDeleted</code>).	ch09 mongodb indexes soft-delete smartcat
What is wrong here?<pre><code>if (await repo.ExistsAsync(accountId, name)) throw new DuplicateNameException(name);<br>await repo.InsertAsync(rate);</code></pre>	TOCTOU race (review-architecture A28): two requests can both pass the check. Drop the pre-check; rely on the unique index and map <code>DuplicateKey</code> to a domain error.	ch09 mongodb indexes review
You add a nullable field that will be backfilled and must be unique. What index do you create first?	A unique index with a partial filter excluding null/missing (A26); replace it with the final index after the backfill, in a later migration.	ch09 mongodb indexes migrations review
How does a TTL index work, and what must you document (A38/A39)?	Mongo deletes documents after <code>ExpireAfter</code> from a DateTime field (background run about every minute). Name the duration (no magic number); document who writes it, who relies on cleanup, worst-case staleness, crash behaviour.	ch09 mongodb indexes ttl review
What are the Smartcat index name prefixes?	<code>UDX_</code> for unique, <code>IDX_</code> for non-unique (for example <code>IDX_State_UpTime</code>). Keep existing <code>IX_</code> names.	ch09 mongodb indexes naming smartcat
Why not rename an old <code>IX_</code> index to the new naming convention?	A rename is a drop + rebuild: long on big collections, and for a unique index a window with no uniqueness. The name is cosmetic; the rebuild is not.	ch09 mongodb indexes naming smartcat
What is the Smartcat two-place index pattern?	Declare every index in a <b>migration</b> (<code>EnsureIndexAsync</code>, for populated DBs) <b>and</b> in the <b>repository constructor</b> (<code>SafeCreateIndex</code>, for fresh DBs), with the same name and keys.	ch09 indexes two-place smartcat
What does <code>SafeCreateIndex</code> do on a non-empty collection?	Throws <code>InvalidOperationException</code>: &quot;Can't create index because collection is not empty. You should write proper migration script.&quot;	ch09 indexes two-place smartcat
What breaks if an index is only in the repository? Only in the migration?	Only repository: production deploy fails (<code>SafeCreateIndex</code> throws on populated data). Only migration: new environments and tests have no index.	ch09 indexes two-place smartcat
Why not just create indexes implicitly at startup on production?	Building an index on a large live collection must be scheduled (migration phase, replication care, before the code needs it). At startup it would load the primary during a deploy. The throw forces a migration.	ch09 indexes two-place
Which review rule flags a migration index with no <code>SafeCreateIndex</code> entry?	review-architecture A25 (MAJOR): a fresh-environment breaker. (A24's &quot;XOR&quot; wording conflicts; the canon is both places, one identical definition.)	ch09 indexes review smartcat
What does review-tests-backend T15 ask for a new index?	Tests for both paths: fresh-env (repository creates it on an empty collection) and upgrade (migration creates it on a populated one).	ch09 indexes testing review
Name the four migration phases in order.	<code>InitBeforeRelease</code> &rarr; <code>BeforeRelease</code> &rarr; (code deploy) &rarr; <code>InitAfterRelease</code> &rarr; <code>AfterRelease</code>. Init phases are idempotent (upsert tracking); Before/After run once (insert tracking).	ch09 migrations smartcat
What belongs in BeforeRelease vs AfterRelease?	Before: schema prep the new code needs and old code tolerates (indexes, new optional fields). After: backfills, cleanup, dropping what old code used.	ch09 migrations smartcat
What is the key fact about a rolling update for migrations?	Old and new code run at the same time against the same database. Before-changes must be safe for old code; After-changes may assume only new code.	ch09 migrations deployment
Why must dropping a finished one-shot task collection be an AfterRelease migration?	A pod of the previous release is still running before the release and would recreate the collection/task (real PTS example).	ch09 migrations pts smartcat
Why is a backfill in BeforeRelease usually wrong?	Old code keeps writing old-shape documents after the backfill. Backfill in AfterRelease when only new code writes, and make new code write the new shape from day one.	ch09 migrations traps
What is expand/contract?	Zero-downtime schema change in steps: expand (add, tolerated by old code) &rarr; migrate (write both, backfill) &rarr; switch reads &rarr; contract (remove old shape in a later release).	ch09 migrations expand-contract
How do you rename a Mongo field safely?	Never in one step. Add the new field, write both, backfill in AfterRelease, read new with fallback, stop writing old, then remove old in a later release. Test with raw old-shape BSON.	ch09 migrations expand-contract
Why can adding a field break old pods during a rolling update?	Many models do not ignore unknown BSON elements, so an old pod fails to deserialize a document a new pod wrote. Release the reader first, or gate the first write until after the rollout.	ch09 migrations traps pts smartcat
What does &quot;Mongo changes are additive only&quot; mean at Smartcat?	New fields nullable or <code>[BsonIgnoreIfDefault]</code>; never rename, retype or repurpose a field; reads tolerate old-shape documents.	ch09 migrations smartcat
What happens to a migration class that is not added to <code>Pack.cs</code>?	It never runs. Register it with <code>BeforeRelease.Add&lt;T&gt;()</code> or <code>AfterRelease.Add&lt;T&gt;()</code> in the pack of <code>Migrations/Migration-YYYY-N/</code>.	ch09 migrations smartcat
Where do monolith migrations live, and how are they run?	Centralized in <code>smartcat/Migrations/</code> (not per feature), as packs <code>Migration-YYYY-N/{Before,After}</code>; run with the <code>migrate</code> verb of the same binary.	ch09 migrations smartcat
List the features of a good batched data migration.	<ul><li>Filter only unmigrated docs (idempotent)</li><li>Cursor with <code>BatchSize</code></li><li>Project <code>_id</code></li><li><code>UpdateManyAsync</code> + <code>$in</code> per batch</li><li><code>ProgressReporter</code></li><li><code>await Throtle()</code> per batch</li></ul>	ch09 migrations data-migration smartcat
Review this migration:<pre><code>var all = await col.Find(_ =&gt; true).ToListAsync();<br>foreach (var d in all)<br>    await col.UpdateOneAsync(x =&gt; x.Id == d.Id, Builders&lt;ProjectTask&gt;.Update.Set(x =&gt; x.Priority, 1));</code></pre>	Whole collection in memory; one round trip per doc; no throttle; no progress; not idempotent; uses the domain model. Use a filtered cursor, batch <code>UpdateMany</code>, <code>ProgressReporter</code>, <code>Throtle()</code>, <code>BsonDocument</code>.	ch09 migrations data-migration review
Why make a data migration filter select only not-yet-migrated documents?	So a re-run after a crash continues where it stopped and never double-applies: the migration is idempotent.	ch09 migrations data-migration
What is <code>MongoIndexReplicationGuard</code> for?	Wrap several consecutive index builds in one migration; it prevents replicas from hitting 100% CPU.	ch09 migrations indexes smartcat
Why never reuse domain models inside migrations?	A migration is frozen in time while domain models change; domain invariants/required fields expect the new shape; it couples migrations to module internals; domain models may not ignore extra elements.	ch09 migrations models
What model should a migration use instead?	<code>BsonDocument</code>, or a minimal private class inside the migration marked <code>[BsonIgnoreExtraElements]</code> with only the fields it needs.	ch09 migrations models smartcat
How do monolith Mongo tests get a database?	<code>MongoTest</code>/<code>LegacyBaseTest</code> start an ephemeral replica-set <code>mongod</code> without Docker. The <code>DockerBasedTests</code> category is a legacy name.	ch09 testing mongodb smartcat
What does review-tests-backend T2 require for a schema change?	An ephemeral-Mongo test that inserts an old-shape document, reads it with new code, and updates it so the new field propagates.	ch09 testing review
Why insert raw <code>BsonDocument</code> in a compatibility test?	Inserting through the new model only tests the new shape. Raw BSON reproduces exactly what production holds (T13).	ch09 testing review
What does T4 (null vs missing vs zero) ask you to test?	Filters on nullable fields must be tested with the value null, the field missing (raw BSON), and zero/default.	ch09 testing review
Interviewer: what question separates senior from staff on Mongo schema changes?	&quot;Old and new code run together for 20 minutes during a deploy: which of your changes is unsafe in that window?&quot; Staff reasons about the rolling-update window and multi-release expand/contract.	ch09 interviewer migrations
Interviewer: name three red flags in a Mongo answer.	&quot;Index every field&quot;; unthrottled one-shot <code>UpdateMany</code> or <code>ToList()</code> backfill; read-modify-write without concurrency control; rename in one release; <code>AllowDiskUse</code> for a 16 MB error.	ch09 interviewer
Interviewer: good probe for migration maturity?	&quot;Your backfill crashed at 60%. What happens when you run it again?&quot; Look for idempotent filters, batches, progress and throttling.	ch09 interviewer migrations
