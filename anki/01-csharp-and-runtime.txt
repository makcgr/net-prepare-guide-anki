What is the difference between a value type and a reference type?	A value type holds its data directly; assignment copies the data. A reference type holds a reference to a heap object; assignment copies the reference, so both variables see the same object.	ch01 value-types
Is it true that structs always live on the stack?	No. A value lives where its container lives.<ul><li>struct field of a class: on the heap, inside the object</li><li>array of structs: on the heap</li><li>captured or async locals: moved to a heap object</li><li>boxed struct: on the heap</li></ul>The real contract is copy semantics, not location.	ch01 memory stack-heap
Where does a value-type local of an <code>async</code> method live if it is used after an <code>await</code>?	In a field of the compiler-generated state machine, which is boxed to the heap when the method really suspends. So it is not on the stack.	ch01 memory async
What is wrong with this code?<pre><code>var points = new List&lt;PointStruct&gt; { new() };<br>var p = points[0];<br>p.X = 5;</code></pre>	The indexer returns a <b>copy</b> of the struct. <code>p.X = 5</code> changes the local copy only. You must write it back: <code>points[0] = p;</code>. (<code>points[0].X = 5</code> does not compile: CS1612.)	ch01 value-types struct
When is a struct a good choice?	Small (about 16 bytes or less), logically a single value, immutable, and not boxed often. Large structs cost a copy on every assignment and call.	ch01 value-types struct
What is a defensive copy, and how does <code>readonly struct</code> help?	When you call a method on a struct through a readonly field or an <code>in</code> parameter, the compiler copies the struct first, because the method could change it. A <code>readonly struct</code> guarantees no changes, so the copy is not needed.	ch01 value-types struct performance
Compare <code>ref</code>, <code>out</code> and <code>in</code> parameters.	<code>ref</code>: must be set before the call; callee may write. <code>out</code>: need not be set; callee must write (TryParse). <code>in</code>: read-only reference; passes a big struct without a copy.	ch01 parameters
A method gets a <code>List&lt;int&gt;</code> parameter and does <code>list = new List&lt;int&gt;();</code>. Does the caller see a new list?	No. The reference is passed <b>by value</b>. The callee can change the content of the caller's list, but reassigning the parameter changes only its local copy of the reference. Use <code>ref</code> to reassign.	ch01 parameters reference-types
What is boxing?	Converting a value type to <code>object</code> or to an interface. The runtime allocates a heap object and copies the value into it. Unboxing is the cast back: type check plus copy.	ch01 boxing
What happens here?<pre><code>object boxed = 42;<br>long value = (long)boxed;</code></pre>	<code>InvalidCastException</code>. Unboxing must use the exact type (<code>int</code>). Write <code>(long)(int)boxed</code>.	ch01 boxing
Name four places where boxing hides.	<ul><li>non-generic collections (<code>ArrayList</code>)</li><li>assigning a struct to an interface variable</li><li><code>string.Format</code> with value-type arguments</li><li>a struct dictionary key without <code>IEquatable&lt;T&gt;</code> (default <code>ValueType.Equals(object)</code>)</li></ul>	ch01 boxing performance
Why is a <code>readonly record struct</code> a good dictionary key?	It implements <code>IEquatable&lt;T&gt;</code> and a field-based <code>GetHashCode</code> for you. No boxing on <code>Equals</code> and no reflection, unlike the default <code>ValueType.Equals</code>.	ch01 records boxing collections
Why does <code>a == b</code> return true for two different string objects with the same text?	<code>string</code> overloads the <code>==</code> operator to compare content. Cast both to <code>object</code> and <code>==</code> compares references instead.	ch01 strings equality
What is string interning?	The runtime keeps one shared instance per distinct literal, so all equal literals point to the same object. Strings built at run time are not interned unless you call <code>string.Intern</code>, and interned strings live for the whole process.	ch01 strings
What is wrong with building a long string with <code>+=</code> in a loop?	Strings are immutable, so each <code>+=</code> allocates a new string and copies everything: O(n^2) work and n allocations. Use <code>StringBuilder</code> or <code>string.Join</code>.	ch01 strings performance
How do you compare a language code or file extension case-insensitively?	<code>string.Equals(a, b, StringComparison.OrdinalIgnoreCase)</code>, and <code>StringComparer.OrdinalIgnoreCase</code> for dictionary keys. Not <code>ToLower() ==</code>: it allocates and is culture-sensitive (Turkish I).	ch01 strings
How is <code>==</code> resolved differently from <code>Equals</code>?	<code>==</code> is an operator chosen at <b>compile time</b> from the static types. <code>Equals</code> is virtual and chosen at <b>run time</b>. <code>object x == object y</code> compares references even if both are equal strings.	ch01 equality
State the <code>GetHashCode</code> contract.	<ul><li>If <code>a.Equals(b)</code>, then the hash codes must be equal.</li><li>Equal hash codes do not mean equal objects.</li><li>The hash must not change while the object is a key in a hash collection.</li></ul>	ch01 equality hashing
A class is a key in a <code>HashSet</code>. You change a property used in <code>GetHashCode</code>. What happens?	The item is now in the bucket of the old hash. <code>Contains</code> and <code>Remove</code> look in the new bucket and fail: the item is lost inside the set. Keys must be immutable.	ch01 equality hashing collections
Your <code>Equals</code> ignores case. What must <code>GetHashCode</code> do?	Use the same rule: for example <code>StringComparer.OrdinalIgnoreCase.GetHashCode(Name)</code>. Otherwise two equal objects get different hashes and the contract breaks.	ch01 equality hashing
What does a <code>record</code> generate for you?	Value equality (<code>Equals</code>, <code>==</code>, <code>GetHashCode</code>), <code>ToString</code>, deconstruction for positional records, and non-destructive mutation with <code>with</code>.	ch01 records
Are these two records equal?<pre><code>record Batch(string Name, List&lt;string&gt; Items);<br>var a = new Batch(&quot;x&quot;, new() { &quot;1&quot; });<br>var b = new Batch(&quot;x&quot;, new() { &quot;1&quot; });</code></pre>	No. Record equality is <b>shallow</b>: <code>Items</code> is compared by reference, and these are two different lists.	ch01 records equality
Does <code>with</code> deep-copy a record?	No. It is a shallow copy (memberwise clone plus the changed properties). A list property is shared between the original and the copy.	ch01 records
What is <code>EqualityContract</code> in a record?	A generated property that returns the run-time type. Equality checks it, so a base record and a derived record with the same values are not equal.	ch01 records
What is the difference between <code>init</code> and <code>required</code>?	<code>init</code>: the property can be set only during object initialization. <code>required</code>: the caller <b>must</b> set it in the initializer (compiler error CS9035 otherwise). They are often combined.	ch01 records required init
What does <code>public required Guid? ProjectId { get; init; }</code> mean?	Every caller must set <code>ProjectId</code> explicitly, but <code>null</code> is a valid value. <code>required</code> is about being set, not about being non-null.	ch01 required nullable
At Smartcat, how are mandatory fields of a Mongo model declared?	<code>public required X Foo { get; init; }</code> with <code>[BsonElement(&quot;camelCase&quot;)]</code> and <code>[BsonRequired]</code>. Optional fields: <code>[BsonIgnoreIfDefault]</code> / <code>[BsonIgnoreIfNull]</code>. A public <code>set</code> is flagged (rule D16, MINOR).	ch01 smartcat mongodb required init
At Smartcat, how are request DTOs different from Mongo models?	DTOs: no constructors, public setters, no attributes. Mongo models: <code>required</code> + <code>init</code> and Bson attributes. Separate models for DB, API input and API output.	ch01 smartcat dto
Do nullable reference types add run-time null checks?	No. They are a compile-time flow analysis only. <code>string</code> and <code>string?</code> are the same run-time type. Deserializers, reflection and callers without NRT can still pass null, so validate at boundaries.	ch01 nullable
What does the null-forgiving operator <code>x!</code> do?	It silences the nullable warning. It adds no check. It is a claim the compiler cannot verify, so in review ask why it is safe.	ch01 nullable
What is <code>[NotNullWhen(true)]</code> used for?	On an <code>out</code> parameter of a Try method: it tells the compiler the value is not null when the method returns true, so the caller needs no <code>!</code>.	ch01 nullable
At Smartcat, how is NRT enabled in the monolith vs newer services?	Monolith: per file, <code>#nullable enable</code> at the top of new files (<code>#nullable restore</code> in old files you change). Newer services (project-tasks-service, smartcat-ai-agents): <code>&lt;Nullable&gt;enable&lt;/Nullable&gt;</code> in <code>Directory.Build.props</code>.	ch01 smartcat nullable
Why does a nullable warning fail the build in Smartcat repos?	<code>TreatWarningsAsErrors=true</code> in <code>Directory.Build.props</code>. So review focuses on <code>!</code> and boundaries; if it compiles, the nullable flow is consistent.	ch01 smartcat nullable build
What is covariance? Give an example.	Using a more derived type where a less derived one is expected, for output positions. <code>IEnumerable&lt;out T&gt;</code>: an <code>IEnumerable&lt;string&gt;</code> can be used as <code>IEnumerable&lt;object&gt;</code>.	ch01 generics variance
What is contravariance? Give an example.	The opposite direction, for input positions. <code>Action&lt;in T&gt;</code>: an <code>Action&lt;object&gt;</code> can be used as <code>Action&lt;string&gt;</code>. Also <code>IComparer&lt;in T&gt;</code>.	ch01 generics variance
Why is <code>List&lt;string&gt;</code> not a <code>List&lt;object&gt;</code>?	<code>List&lt;T&gt;</code> is invariant: it both reads and writes T. If it were covariant, you could add an <code>int</code> to a list of strings. Variance works only on interfaces and delegates, and only for reference types.	ch01 generics variance
What does this do?<pre><code>object[] items = new string[1];<br>items[0] = 42;</code></pre>	It compiles but throws <code>ArrayTypeMismatchException</code> at run time. Arrays are covariant (a legacy feature), which is not type-safe, so every write is checked.	ch01 generics variance arrays
What is the difference between a delegate field and an <code>event</code>?	An event restricts outside code to <code>+=</code> and <code>-=</code>. Only the owning class can invoke it or replace the whole list.	ch01 delegates events
How can an event cause a memory leak?	The publisher's delegate list holds a reference to every subscriber. A long-lived publisher (singleton, static event) keeps short-lived subscribers alive if they never unsubscribe. Unsubscribe in <code>Dispose</code>.	ch01 events memory-leak
What does this print, and why?<pre><code>var actions = new List&lt;Action&gt;();<br>for (var i = 0; i &lt; 3; i++)<br>    actions.Add(() =&gt; Console.Write(i));<br>foreach (var a in actions) a();</code></pre>	<code>333</code>. The lambda captures the <b>variable</b> <code>i</code>, not its value, and a <code>for</code> loop has one <code>i</code>. When the actions run, it is 3. Fix: copy to a local inside the loop.	ch01 closures
Does the closure trap also happen with <code>foreach</code>?	Not since C# 5. Each <code>foreach</code> iteration gets a new variable, so captured values are per iteration. <code>for</code> still shares one variable.	ch01 closures
What does the compiler do with a captured local variable?	It moves it into a generated class (display class) on the heap. The method and the lambda share that one instance. Costs: an allocation, a longer lifetime, and shared state between threads.	ch01 closures memory
What is a <code>static</code> lambda (C# 9)?	A lambda that cannot capture locals or <code>this</code>. The compiler reports an error on accidental capture, so there is no closure allocation.	ch01 closures performance
What is deferred execution in LINQ?	Operators like <code>Where</code> and <code>Select</code> build a pipeline and run only when you enumerate. Captured variables are read at that moment, not when the query was written.	ch01 linq
What does this print?<pre><code>var numbers = new List&lt;int&gt; { 1, 2, 3 };<br>var query = numbers.Select(n =&gt; n * 10);<br>numbers.Add(4);<br>Console.WriteLine(string.Join(&quot;,&quot;, query));</code></pre>	<code>10,20,30,40</code>. The query is enumerated by <code>string.Join</code>, after <code>Add</code>.	ch01 linq
What is multiple enumeration and why is it a problem?	Enumerating the same <code>IEnumerable&lt;T&gt;</code> twice runs the whole pipeline twice: double database or CPU work, and results can differ if the source changed. Materialize once with <code>ToList()</code>.	ch01 linq
A method needs to enumerate its input twice and read Count. Which parameter type?	<code>IReadOnlyCollection&lt;T&gt;</code> or <code>IReadOnlyList&lt;T&gt;</code>. Accept <code>IEnumerable&lt;T&gt;</code> only if you enumerate once.	ch01 linq api-design
Compare <code>IEnumerable&lt;T&gt;</code> and <code>IQueryable&lt;T&gt;</code>.	<code>IEnumerable</code>: lambdas are delegates, run in memory. <code>IQueryable</code>: lambdas are expression trees, translated by a provider (EF Core, MongoDB driver) and run in the database. Untranslatable methods throw or move work to memory.	ch01 linq iqueryable
A repository returns <code>IEnumerable&lt;T&gt;</code> built from <code>IQueryable&lt;T&gt;</code>. The caller adds <code>.Where(...)</code>. Where does the filter run?	In memory, after the provider loaded the unfiltered data. This can become an unbounded full-collection scan (review rule A21).	ch01 linq iqueryable smartcat
What does the Smartcat style rule D9 say about LINQ?	Use <code>Any(predicate)</code> instead of <code>Where(predicate).Any()</code>, and <code>Any()</code> instead of <code>Count() &gt; 0</code>. <code>Count()</code> may enumerate everything; <code>Any()</code> stops at the first item.	ch01 smartcat linq
How should lambda parameters be named in Smartcat code?	Meaningful names: <code>projectCosts.Sum(pc =&gt; pc.Amount)</code>. The underscore <code>_</code> only for a parameter that is not used.	ch01 smartcat linq naming
What is the difference between <code>throw;</code> and <code>throw ex;</code>?	<code>throw;</code> rethrows and keeps the original stack trace. <code>throw ex;</code> resets the stack trace to the current line. To add context, wrap: <code>throw new X(&quot;...&quot;, ex)</code>.	ch01 exceptions
How do you rethrow an exception later, on another thread, and keep its stack trace?	<code>ExceptionDispatchInfo.Capture(exception).Throw()</code>. This is what <code>await</code> uses internally.	ch01 exceptions
When does an exception filter (<code>catch ... when (...)</code>) run, and why is that useful?	Before the stack unwinds. If it returns false, the runtime keeps searching as if the catch did not exist. The original stack stays intact (better dumps), and you avoid catch-and-rethrow.	ch01 exceptions
What is wrong with this code?<pre><code>try { Check(id); return true; }<br>catch { return false; }</code></pre>	Exception as a success indicator (Smartcat rule D8, MAJOR). Exceptions are expensive and hide normal flow. Use <code>bool TryX(out T)</code> or a <code>Result&lt;T&gt;</code>. Also: an empty catch swallows every error type.	ch01 exceptions smartcat
Should you log <code>OperationCanceledException</code> as an error?	Usually no. It is the normal result of cancellation (client disconnected, shutdown). Let it propagate or handle it as cancellation, not as a failure.	ch01 exceptions cancellation
At Smartcat, how do Kafka handlers treat different exception types?	<code>ValidationException</code>: log and skip. <code>TransientException</code>: retry, then DLQ. Other exceptions: DLQ at once. Wrap with <code>EventHandlerException(responsibleTeams, e)</code> so alerts reach the right team. See chapter 07.	ch01 smartcat exceptions kafka
When do you implement <code>IAsyncDisposable</code>?	When cleanup is I/O (flushing a buffer to the network, closing a connection gracefully). <code>await using</code> calls <code>DisposeAsync</code> without blocking a thread.	ch01 idisposable async
What is the ownership rule for disposal?	Dispose what you create; do not dispose what you were given (for example a stream or <code>HttpClient</code> from the constructor). In DI, the container disposes the services it created.	ch01 idisposable di
When does a class need a finalizer?	Only when it directly owns an unmanaged resource (a raw handle). Even then, prefer wrapping the handle in a <code>SafeHandle</code> so you never write a finalizer.	ch01 gc finalizers
Why does <code>Dispose()</code> call <code>GC.SuppressFinalize(this)</code>?	The resources are already released, so the finalizer does not need to run. The object then avoids the finalization queue and can be collected in the first GC that finds it unreachable.	ch01 gc finalizers idisposable
In <code>Dispose(bool disposing)</code>, why must you not touch managed fields when <code>disposing</code> is false?	False means the call comes from the finalizer. Other managed objects may already be finalized or collected, so only unmanaged resources are safe to release.	ch01 gc finalizers
Why does an object with a finalizer cost more for the GC?	It survives at least one extra collection: the GC queues it, the finalizer thread runs it, and only the next GC frees it. So it is often promoted to an older generation.	ch01 gc finalizers
Explain GC generations and why they work.	Gen 0: new objects, collected often and cheaply. Gen 1: a buffer. Gen 2: long-lived, collected rarely (full GC). It works because most objects die young, so collecting only gen 0 is small and fast.	ch01 gc
What is the LOH and what problem does it cause?	Large object heap: objects of 85,000 bytes or more. Collected only with gen 2 and not compacted by default, so it fragments. Reading whole files into <code>byte[]</code> creates LOH pressure and full GCs. Stream and use <code>ArrayPool&lt;T&gt;</code>.	ch01 gc loh
Server GC vs Workstation GC?	Server: one heap and GC thread per core, higher throughput, more memory; default for ASP.NET Core. Workstation: one heap, for desktop apps. Since .NET 9, DATAS adapts the Server GC heap count to the load (helps in containers).	ch01 gc
Can a .NET app have a memory leak? Give examples.	Yes: references you forgot. Static collections that only grow, caches with no limit, event subscriptions from a long-lived publisher, closures that capture large objects.	ch01 gc memory-leak
What is <code>Span&lt;T&gt;</code>?	A <code>ref struct</code> view over contiguous memory (array, <code>stackalloc</code>, native memory, string). Slicing does not copy or allocate. Used in parsers and buffers.	ch01 span
Why can a <code>Span&lt;T&gt;</code> not be a class field or live across <code>await</code>?	It is a <code>ref struct</code>: stack-only by design, because it can point into the stack. So no class fields, no boxing, no lambda capture, and not alive across <code>await</code> (the state machine is on the heap). Use <code>Memory&lt;T&gt;</code> there.	ch01 span async
What is the trap with <code>ArrayPool&lt;byte&gt;.Shared.Rent(size)</code>?	It can return a <b>larger</b> array than requested, with old data in it. Always use the length you asked for (<code>buffer.AsMemory(0, size)</code>) and return the array in <code>finally</code>.	ch01 span performance
Why prefer <code>x is null</code> over <code>x == null</code>?	<code>==</code> can be overloaded by the type; <code>is null</code> always checks the reference.	ch01 pattern-matching
What does this pattern match?<pre><code>items is [var first, .., var last]</code></pre>	A list pattern (C# 11): a list with at least two elements; binds the first and the last. <code>..</code> is a slice that matches any number of elements.	ch01 pattern-matching
Why might you leave out the <code>_</code> arm in a switch expression over an enum?	The compiler then warns when a value is not handled. With <code>TreatWarningsAsErrors</code>, adding a new enum value breaks the build until every switch handles it.	ch01 pattern-matching
Complexity: <code>List&lt;T&gt;.Contains</code>, <code>HashSet&lt;T&gt;.Contains</code>, <code>SortedDictionary</code> lookup?	O(n), O(1) average, O(log n).	ch01 collections complexity
When do you choose <code>FrozenDictionary</code> (.NET 8)?	For read-only data built once (at startup) and read often, for example a map of file extensions to parsers. Reads are faster than <code>Dictionary</code>; creation is slow. Never build it per request.	ch01 collections frozen
<code>ImmutableList&lt;T&gt;</code> vs <code>ImmutableArray&lt;T&gt;</code>?	<code>ImmutableList</code>: balanced tree, O(log n) for read and change, shares structure. <code>ImmutableArray</code>: array wrapper, O(1) index reads, but each change copies the array, O(n).	ch01 collections immutable
Interviewer: which snippet-based openers test the runtime model well?	The <code>for</code> closure loop, a mutable <code>HashSet</code> key, a record with a <code>List</code> property, and <code>object == object</code> on two equal strings. Ask the candidate to predict the output and explain.	ch01 interviewer
Interviewer: what follow-up separates a Senior from a Staff answer on equality?	Senior: knows the full <code>GetHashCode</code> contract and shallow record equality. Staff: also sets team-level rules (records for DTOs, immutable keys, analyzers) and links it to real incidents.	ch01 interviewer equality
Interviewer: name three red flags in a fundamentals round.	Confident wrong facts (strings are value types; GC prevents all leaks); using <code>!</code> or <code>catch {}</code> to hide problems; optimizing with structs or <code>Span</code> everywhere with no measurement.	ch01 interviewer
Interviewer: a candidate says &quot;structs live on the stack&quot;. What is a good probe?	Ask: where does a struct field of a class live? A struct in an array? A local captured by a lambda or used after <code>await</code>? A strong candidate separates the contract (copy semantics) from the implementation.	ch01 interviewer memory
