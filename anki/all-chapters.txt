What is the difference between a value type and a reference type?	A value type holds its data directly; assignment copies the data. A reference type holds a reference to a heap object; assignment copies the reference, so both variables see the same object.	ch01 value-types	DotNet Interview Guide::01 CSharp and the .NET runtime
Is it true that structs always live on the stack?	No. A value lives where its container lives.<ul><li>struct field of a class: on the heap, inside the object</li><li>array of structs: on the heap</li><li>captured or async locals: moved to a heap object</li><li>boxed struct: on the heap</li></ul>The real contract is copy semantics, not location.	ch01 memory stack-heap	DotNet Interview Guide::01 CSharp and the .NET runtime
Where does a value-type local of an <code>async</code> method live if it is used after an <code>await</code>?	In a field of the compiler-generated state machine, which is boxed to the heap when the method really suspends. So it is not on the stack.	ch01 memory async	DotNet Interview Guide::01 CSharp and the .NET runtime
What is wrong with this code?<pre><code>var points = new List&lt;PointStruct&gt; { new() };<br>var p = points[0];<br>p.X = 5;</code></pre>	The indexer returns a <b>copy</b> of the struct. <code>p.X = 5</code> changes the local copy only. You must write it back: <code>points[0] = p;</code>. (<code>points[0].X = 5</code> does not compile: CS1612.)	ch01 value-types struct	DotNet Interview Guide::01 CSharp and the .NET runtime
When is a struct a good choice?	Small (about 16 bytes or less), logically a single value, immutable, and not boxed often. Large structs cost a copy on every assignment and call.	ch01 value-types struct	DotNet Interview Guide::01 CSharp and the .NET runtime
What is a defensive copy, and how does <code>readonly struct</code> help?	When you call a method on a struct through a readonly field or an <code>in</code> parameter, the compiler copies the struct first, because the method could change it. A <code>readonly struct</code> guarantees no changes, so the copy is not needed.	ch01 value-types struct performance	DotNet Interview Guide::01 CSharp and the .NET runtime
Compare <code>ref</code>, <code>out</code> and <code>in</code> parameters.	<code>ref</code>: must be set before the call; callee may write. <code>out</code>: need not be set; callee must write (TryParse). <code>in</code>: read-only reference; passes a big struct without a copy.	ch01 parameters	DotNet Interview Guide::01 CSharp and the .NET runtime
A method gets a <code>List&lt;int&gt;</code> parameter and does <code>list = new List&lt;int&gt;();</code>. Does the caller see a new list?	No. The reference is passed <b>by value</b>. The callee can change the content of the caller's list, but reassigning the parameter changes only its local copy of the reference. Use <code>ref</code> to reassign.	ch01 parameters reference-types	DotNet Interview Guide::01 CSharp and the .NET runtime
What is boxing?	Converting a value type to <code>object</code> or to an interface. The runtime allocates a heap object and copies the value into it. Unboxing is the cast back: type check plus copy.	ch01 boxing	DotNet Interview Guide::01 CSharp and the .NET runtime
What happens here?<pre><code>object boxed = 42;<br>long value = (long)boxed;</code></pre>	<code>InvalidCastException</code>. Unboxing must use the exact type (<code>int</code>). Write <code>(long)(int)boxed</code>.	ch01 boxing	DotNet Interview Guide::01 CSharp and the .NET runtime
Name four places where boxing hides.	<ul><li>non-generic collections (<code>ArrayList</code>)</li><li>assigning a struct to an interface variable</li><li><code>string.Format</code> with value-type arguments</li><li>a struct dictionary key without <code>IEquatable&lt;T&gt;</code> (default <code>ValueType.Equals(object)</code>)</li></ul>	ch01 boxing performance	DotNet Interview Guide::01 CSharp and the .NET runtime
Why is a <code>readonly record struct</code> a good dictionary key?	It implements <code>IEquatable&lt;T&gt;</code> and a field-based <code>GetHashCode</code> for you. No boxing on <code>Equals</code> and no reflection, unlike the default <code>ValueType.Equals</code>.	ch01 records boxing collections	DotNet Interview Guide::01 CSharp and the .NET runtime
Why does <code>a == b</code> return true for two different string objects with the same text?	<code>string</code> overloads the <code>==</code> operator to compare content. Cast both to <code>object</code> and <code>==</code> compares references instead.	ch01 strings equality	DotNet Interview Guide::01 CSharp and the .NET runtime
What is string interning?	The runtime keeps one shared instance per distinct literal, so all equal literals point to the same object. Strings built at run time are not interned unless you call <code>string.Intern</code>, and interned strings live for the whole process.	ch01 strings	DotNet Interview Guide::01 CSharp and the .NET runtime
What is wrong with building a long string with <code>+=</code> in a loop?	Strings are immutable, so each <code>+=</code> allocates a new string and copies everything: O(n^2) work and n allocations. Use <code>StringBuilder</code> or <code>string.Join</code>.	ch01 strings performance	DotNet Interview Guide::01 CSharp and the .NET runtime
How do you compare a language code or file extension case-insensitively?	<code>string.Equals(a, b, StringComparison.OrdinalIgnoreCase)</code>, and <code>StringComparer.OrdinalIgnoreCase</code> for dictionary keys. Not <code>ToLower() ==</code>: it allocates and is culture-sensitive (Turkish I).	ch01 strings	DotNet Interview Guide::01 CSharp and the .NET runtime
How is <code>==</code> resolved differently from <code>Equals</code>?	<code>==</code> is an operator chosen at <b>compile time</b> from the static types. <code>Equals</code> is virtual and chosen at <b>run time</b>. <code>object x == object y</code> compares references even if both are equal strings.	ch01 equality	DotNet Interview Guide::01 CSharp and the .NET runtime
State the <code>GetHashCode</code> contract.	<ul><li>If <code>a.Equals(b)</code>, then the hash codes must be equal.</li><li>Equal hash codes do not mean equal objects.</li><li>The hash must not change while the object is a key in a hash collection.</li></ul>	ch01 equality hashing	DotNet Interview Guide::01 CSharp and the .NET runtime
A class is a key in a <code>HashSet</code>. You change a property used in <code>GetHashCode</code>. What happens?	The item is now in the bucket of the old hash. <code>Contains</code> and <code>Remove</code> look in the new bucket and fail: the item is lost inside the set. Keys must be immutable.	ch01 equality hashing collections	DotNet Interview Guide::01 CSharp and the .NET runtime
Your <code>Equals</code> ignores case. What must <code>GetHashCode</code> do?	Use the same rule: for example <code>StringComparer.OrdinalIgnoreCase.GetHashCode(Name)</code>. Otherwise two equal objects get different hashes and the contract breaks.	ch01 equality hashing	DotNet Interview Guide::01 CSharp and the .NET runtime
What does a <code>record</code> generate for you?	Value equality (<code>Equals</code>, <code>==</code>, <code>GetHashCode</code>), <code>ToString</code>, deconstruction for positional records, and non-destructive mutation with <code>with</code>.	ch01 records	DotNet Interview Guide::01 CSharp and the .NET runtime
Are these two records equal?<pre><code>record Batch(string Name, List&lt;string&gt; Items);<br>var a = new Batch(&quot;x&quot;, new() { &quot;1&quot; });<br>var b = new Batch(&quot;x&quot;, new() { &quot;1&quot; });</code></pre>	No. Record equality is <b>shallow</b>: <code>Items</code> is compared by reference, and these are two different lists.	ch01 records equality	DotNet Interview Guide::01 CSharp and the .NET runtime
Does <code>with</code> deep-copy a record?	No. It is a shallow copy (memberwise clone plus the changed properties). A list property is shared between the original and the copy.	ch01 records	DotNet Interview Guide::01 CSharp and the .NET runtime
What is <code>EqualityContract</code> in a record?	A generated property that returns the run-time type. Equality checks it, so a base record and a derived record with the same values are not equal.	ch01 records	DotNet Interview Guide::01 CSharp and the .NET runtime
What is the difference between <code>init</code> and <code>required</code>?	<code>init</code>: the property can be set only during object initialization. <code>required</code>: the caller <b>must</b> set it in the initializer (compiler error CS9035 otherwise). They are often combined.	ch01 records required init	DotNet Interview Guide::01 CSharp and the .NET runtime
What does <code>public required Guid? ProjectId { get; init; }</code> mean?	Every caller must set <code>ProjectId</code> explicitly, but <code>null</code> is a valid value. <code>required</code> is about being set, not about being non-null.	ch01 required nullable	DotNet Interview Guide::01 CSharp and the .NET runtime

Do nullable reference types add run-time null checks?	No. They are a compile-time flow analysis only. <code>string</code> and <code>string?</code> are the same run-time type. Deserializers, reflection and callers without NRT can still pass null, so validate at boundaries.	ch01 nullable	DotNet Interview Guide::01 CSharp and the .NET runtime
What does the null-forgiving operator <code>x!</code> do?	It silences the nullable warning. It adds no check. It is a claim the compiler cannot verify, so in review ask why it is safe.	ch01 nullable	DotNet Interview Guide::01 CSharp and the .NET runtime
What is <code>[NotNullWhen(true)]</code> used for?	On an <code>out</code> parameter of a Try method: it tells the compiler the value is not null when the method returns true, so the caller needs no <code>!</code>.	ch01 nullable	DotNet Interview Guide::01 CSharp and the .NET runtime

What is covariance? Give an example.	Using a more derived type where a less derived one is expected, for output positions. <code>IEnumerable&lt;out T&gt;</code>: an <code>IEnumerable&lt;string&gt;</code> can be used as <code>IEnumerable&lt;object&gt;</code>.	ch01 generics variance	DotNet Interview Guide::01 CSharp and the .NET runtime
What is contravariance? Give an example.	The opposite direction, for input positions. <code>Action&lt;in T&gt;</code>: an <code>Action&lt;object&gt;</code> can be used as <code>Action&lt;string&gt;</code>. Also <code>IComparer&lt;in T&gt;</code>.	ch01 generics variance	DotNet Interview Guide::01 CSharp and the .NET runtime
Why is <code>List&lt;string&gt;</code> not a <code>List&lt;object&gt;</code>?	<code>List&lt;T&gt;</code> is invariant: it both reads and writes T. If it were covariant, you could add an <code>int</code> to a list of strings. Variance works only on interfaces and delegates, and only for reference types.	ch01 generics variance	DotNet Interview Guide::01 CSharp and the .NET runtime
What does this do?<pre><code>object[] items = new string[1];<br>items[0] = 42;</code></pre>	It compiles but throws <code>ArrayTypeMismatchException</code> at run time. Arrays are covariant (a legacy feature), which is not type-safe, so every write is checked.	ch01 generics variance arrays	DotNet Interview Guide::01 CSharp and the .NET runtime
What is the difference between a delegate field and an <code>event</code>?	An event restricts outside code to <code>+=</code> and <code>-=</code>. Only the owning class can invoke it or replace the whole list.	ch01 delegates events	DotNet Interview Guide::01 CSharp and the .NET runtime
How can an event cause a memory leak?	The publisher's delegate list holds a reference to every subscriber. A long-lived publisher (singleton, static event) keeps short-lived subscribers alive if they never unsubscribe. Unsubscribe in <code>Dispose</code>.	ch01 events memory-leak	DotNet Interview Guide::01 CSharp and the .NET runtime
What does this print, and why?<pre><code>var actions = new List&lt;Action&gt;();<br>for (var i = 0; i &lt; 3; i++)<br>    actions.Add(() =&gt; Console.Write(i));<br>foreach (var a in actions) a();</code></pre>	<code>333</code>. Does the closure trap also happen with <code>foreach</code>?	Not since C# 5. Each <code>foreach</code> iteration gets a new variable, so captured values are per iteration. <code>for</code> still shares one variable.	ch01 closures	DotNet Interview Guide::01 CSharp and the .NET runtime

Costs: an allocation, a longer lifetime, and shared state between threads.	ch01 closures memory	DotNet Interview Guide::01 CSharp and the .NET runtime
What is a <code>static</code> lambda (C# 9)?	A lambda that cannot capture locals or <code>this</code>. The compiler reports an error on accidental capture, so there is no closure allocation.	ch01 closures performance	DotNet Interview Guide::01 CSharp and the .NET runtime
What is deferred execution in LINQ?	Operators like <code>Where</code> and <code>Select</code> build a pipeline and run only when you enumerate. Captured variables are read at that moment, not when the query was written.	ch01 linq	DotNet Interview Guide::01 CSharp and the .NET runtime

The query is enumerated by <code>string.Join</code>, after <code>Add</code>.	ch01 linq	DotNet Interview Guide::01 CSharp and the .NET runtime
What is multiple enumeration and why is it a problem?	Enumerating the same <code>IEnumerable&lt;T&gt;</code> twice runs the whole pipeline twice: double database or CPU work, and results can differ if the source changed. In memory, after the provider loaded the unfiltered data. What is the difference between <code>throw;</code> and <code>throw ex;</code>?	<code>throw;</code> rethrows and keeps the original stack trace. <code>throw ex;</code> resets the stack trace to the current line. When does an exception filter (<code>catch ... when (...)</code>) run, and why is that useful?	Before the stack unwinds.
